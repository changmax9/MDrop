# Dropover 对齐记录 · 2026-09-05

本轮对照了本机 `/Applications/Dropover.app` 的真实托盘、自定义弹窗，以及项目已有的录屏测量记录。改动位于原有实现工作树，已有未提交修改得到保留。

## 本轮修改

- 圆形关闭、返回和菜单控件保持固定位置，去除额外的悬停缩放、上移；提供统一按下反馈。
- 将菜单的玻璃圆底放到原生菜单标签之外，修复只显示箭头、圆底消失的问题。
- 缩窄紧凑托盘的文件名胶囊，同时调整滚动文字宽度和背景拖动的排除区域。
- 快捷操作保留同一组玻璃表面，从中央展开并原路收回，避免整组替换的闪现；减弱动态效果时直接使用最终布局。
- 紧凑／详情切换持续使用真实玻璃表面，移除原先隐藏真实视图并用静态截图覆盖的过渡。
- 详情页右上角改为托盘自定义弹窗，提供名称、十种指示条颜色、常显指示条、固定和仅在当前桌面显示。紧凑菜单也能打开同一弹窗。
- 托盘选项持久化，兼容旧存档；当前桌面选项会即时更新原生窗口行为。
- 详情页右键菜单保留完整操作；列表／网格选择在同一托盘的收起、展开期间保留。添加文件不再强制退出详情页。
- 整张文件卡片和文件名区域都支持原生拖动；点击、Command 多选、双击和轻微鼠标移动得到明确区分，单个文件的拖动区域不再越界拦截其他文件。
- 文件大小改用实际字节数；自定义弹窗及新增文案覆盖八种语言，大小格式跟随应用语言。
